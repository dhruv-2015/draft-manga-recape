# Manga Recap Studio

A local, single-user AI video production tool for manhwa/manga recap videos.
Title → Story → Script → Scenes → Shots → Images + Voice → Timeline → Render → Final Video.

## Quick Start

```bash
pnpm install
pnpm api        # terminal 1: API server on :3001
pnpm dev        # terminal 2: UI on :3000
```

Open http://localhost:3000
